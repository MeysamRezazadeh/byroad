# Changelog

All notable changes to Byroad are listed here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-26

First public release.

### Added
- Two modes: **Only my sites** (route listed domains) and **Everything** (route all traffic, with a list of sites that always go direct).
- SOCKS5, SOCKS4, HTTP and HTTPS proxy support.
- Current-tab card with a one-click button to route or un-route the site you're on.
- Service presets for YouTube, Google, X, Instagram, Facebook, WhatsApp, Telegram, Discord, Reddit, ChatGPT, GitHub, Spotify, Netflix and Steam. Click again to remove.
- Open-tabs list with checkboxes.
- Right-click menu: *Use proxy for this site* / *Stop using proxy for this site*.
- Warning when the proxy can't be reached, or when another extension controls Chrome's proxy settings.
- Copy and paste for the site list.
- Light and dark themes.
- Toolbar badge showing how many domains are routed.
